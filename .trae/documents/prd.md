## 1. 产品概述

暗黑赛博霓虹风格个人博客，以深色背景、霓虹发光效果和毛玻璃卡片打造极具未来感的视觉体验。
- 目标：提供一个炫酷且实用的个人技术博客，在大量浅色博客中脱颖而出
- 用户：技术爱好者、开发者、追求独特审美的读者
- 差异化：暗黑基调 + 霓虹发光动画 + 玻璃质感卡片，形成强烈的品牌记忆点

## 2. 核心功能

### 2.1 功能模块

1. **首页**：霓虹标题英雄区 + 科技感文章卡片网格 + 发光悬浮动效
2. **文章详情页**：沉浸式暗黑阅读体验 + 霓虹边框评论区
3. **分类/标签页**：网格布局 + 卡片悬浮霓虹发光边框
4. **关于页面**：个人展示 + 霓虹渐变头像

### 2.2 页面详情

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 首页 | 英雄区 | 深色背景+科技网格纹理叠加，霓虹青色标题，前6篇文章自动轮播渐变发光效果 |
| 首页 | 文章卡片 | 毛玻璃卡片(backdrop-filter: blur)排列，悬浮时岩浆渐变边框发光+卡片微抬 |
| 文章详情 | 阅读区 | 深灰背景+最高可读性排版，代码块自带霓虹边框发光 |
| 文章详情 | 评论区 | 头像带霓虹渐变环，评论卡片半透明背景 |
| 布局 | 导航栏 | 透明→模糊深色毛玻璃滚动切换，导航项hover霓虹下划线 |
| 布局 | 页脚 | 科技网格底纹+社交链接霓虹hover效果 |

## 3. 用户界面设计

### 3.1 设计风格

**暗黑赛博霓虹 (Dark Cyberpunk Neon)**
- 主色调：深邃暗色底 (`#0a0a12` / `#111118`)
- 强调色：霓虹青色 (`#00f0ff`) + 电光品红 (`#ff00e5`)
- 字体：
  - 标题：Plus Jakarta Sans / DM Sans（现代几何无衬线，height: 600-800）
  - 正文：系统原生字体栈（阅读舒适优先）
  - 代码：JetBrains Mono
- 卡片风格：毛玻璃 `backdrop-filter: blur(20px)` + 半透明背景 + 悬浮霓虹边框发光
- 动画：CSS `@keyframes` 辉光脉冲，悬浮边框色变，staggered卡片入场
- 背景：纯色深底 + 微妙的CSS网格纹理叠加层

### 3.2 页面设计概览

| 页面 | 模块 | UI元素 |
|------|------|--------|
| 首页 | 英雄区 | `100vh`，深色底+`background-image`网格纹理，标题`font-size: clamp(3rem, 8vw, 6rem)`霓虹青，装饰性发光粒子 |
| 首页 | 网格 | CSS Grid 2-3列响应式，毛玻璃卡片，悬浮时 `box-shadow: 0 0 30px rgba(0,240,255,0.3)` |
| 文章详情 | 内容 | `max-width: 750px`阅读宽度，代码块带`border: 1px solid rgba(0,240,255,0.2)`发光边框 |
| 布局 | Header | `position: sticky`，滚动后`backdrop-filter: blur(20px) saturate(180%)`+深色半透明底 |
| 色彩 | 系统 | `--bg: #0a0a12`, `--card: rgba(255,255,255,0.04)`, `--neon-cyan: #00f0ff`, `--neon-magenta: #ff00e5`, `--text: #e0e0e0` |

### 3.3 响应式

- 桌面优先：1440px最大内容区1200px
- 平板(1024px)：调整为2列
- 手机(<768px)：单列布局，简化导航
